# Interview Plan

Interview Plan is a full-stack web application that helps users prepare for interviews with AI-generated guidance.

The app allows users to:

- create an account and log in
- upload a resume
- add a job description and self-introduction
- generate an interview report with likely questions, skill gaps, and a preparation plan
- create a tailored resume PDF

## Project Structure

- `Frontend` contains the React + Vite client
- `Backend` contains the Express API, authentication, database logic, and AI integration

## Tech Stack

- React
- Vite
- Express
- MongoDB
- Gemini AI
- Puppeteer
